# Безумный транспорт (Crazy Transport)

Учебный проект по дисциплине «Сборка, тестирование и верификация программного
продукта». Цель — спроектировать, реализовать и протестировать приложение про
«безумный транспорт»: создание транспортных средств и проверку корректности их
работы.

В этом репозитории реализован **Земляной Кенгуру-Крот «Терра-Хоппер»** —
вымышленный транспорт стихии Земли. Он прыгает по поверхности, использует
реактор для форсажа дальнего прыжка и перемещается под землёй с помощью бура.
Идея проекта — превратить необычную конструкцию в модель с чёткими правилами:
каждое действие зависит от положения транспорта, его массы и доступных ресурсов.

Модель учитывает пройденную дистанцию, запас силы и энергию реактора.
Обычный прыжок перемещает транспорт на 10 м, дальний — на 30 м
(с форсажем — на 45 м), а подземное бурение — на 40 м.
При пересечении каждой новой отметки 100 м оба ресурса восстанавливаются;
величина восстановления зависит от массы. Недопустимые действия, например
прыжок под землёй или бурение без энергии, вызывают исключения до изменения
состояния. Эти правила и их граничные случаи проверяются тестами.

## Быстрый запуск

Используйте Python 3.12 — эта версия используется в CI. Внешние зависимости
не нужны: реализация, демонстрация и тесты используют стандартную библиотеку.
Выполняйте команды из корня репозитория.

```bash
python demo_script.py
```

Это точка входа для знакомства с работающим проектом: демонстрация показывает
создание транспорта, прыжки, подземный цикл, восстановление ресурсов и ожидаемые
ошибки. Для каждого действия выводится состояние до и после.

Минимальный пример через `Driver`:

```python
from terra_hopper import Driver

driver = Driver()
driver.create_hopper(name="Крот-1", mass_kg=200.0)
driver.basic_jump()
driver.go_underground()
driver.drill_forward()
driver.return_to_surface()
status = driver.get_current_status()  # Печатает и возвращает словарь состояния.
```

Те же действия можно выполнить напрямую через `TerraHopper`, без водителя:

```python
from terra_hopper import TerraHopper

hopper = TerraHopper(name="Крот-1", mass_kg=200.0)
hopper.basic_jump()
hopper.go_underground()
hopper.drill_forward()
hopper.return_to_surface()
status = hopper.get_current_status()  # Печатает и возвращает словарь состояния.
```
